# Web do IES de Sar (vista previa)

Proposta de nova web para o IES de Sar (Santiago de Compostela), feita en WordPress.

**Ver a web:** https://playground.wordpress.net/?blueprint-url=https://raw.githubusercontent.com/tiago765/iesdesar-web/main/blueprint.json

A web ábrese no teu navegador cun WordPress de proba (WordPress Playground). A primeira carga tarda un minuto. Os cambios que fagas non se gardan nin afectan a ninguén.

- `iesdesar.zip`: o tema de WordPress (deseño + contido traído da web antiga do centro).
- `blueprint.json`: instrucións para que WordPress Playground monte a web.
